Foundation自身には異常素材の生成機能やプリセットはありません。通常値と不正値を用意する作業は、外部シミュレーターまたは専用検証環境の固定fixtureで行います。

| 試験 | 既存の検査点 |
| --- | --- |
| readyが無い・ハッシュ不一致・未完了 | 入力は完了扱いにしない |
| 契約対象の型不正・負数・不明な参照 | 元の文字列と由来を残し、規則に応じてQuarantineへ |
| 同一path・同一ハッシュを再処理 | 同じファイルを二重計上しない |
| 新しい版と遅れて到着した実績 | 事象時刻と更新時刻を区別し、Silver/Goldの影響を照合 |
| 画像 | デコード可能性、寸法、Raw原本のSHA-256を照合 |
